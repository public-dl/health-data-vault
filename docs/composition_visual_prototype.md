## 構成と表示設定

ヘッダー・条件選択・01地図／02表／03グラフ・DATA NOTES・任意2地域比較を保持。地図の前に番号なしの「構成をひと目で見る」を追加した。単区分と保健指導全区分は試作対象外。

`web/src/visual-metadata.ts` の `groupVisuals[group_id][category_id]` が色、5階級パレット、姿勢識別子を持つ。表示順・ラベル・定義・階級境界は検証済みreleaseを参照する。`visualGroup` はコピーを作り表示用の色だけを重ねる。元payloadを書き換えず、未設定グループは従来表示を維持する。

`pictograms.tsx` の `PersonShape` は円と単純なSVG pathからなる4姿勢。Unicode絵文字・画像生成・外部素材は不使用。色と姿勢はカテゴリーの識別記号であり、疾病や健康の評価ではない。`CategoryIcon`を地図タイトル・表見出し・グラフの操作凡例で再利用する。

## 100人図

`composition` による既存の構成検証が成立する場合のみ、保存済み派生割合（丸め前）を使用する。独自の分母・割合を作らない。10列×10行の100個を左上からカテゴリー順に連続配置し、5列目と6列目の間に破線を置く。

図だけの近似配分には最大剰余法を使う。各割合の整数部を取り、100との差を小数部分が大きい順へ1個ずつ配分。同順位は既存カテゴリー順。欠損・非有限・負・100超・合計不整合は描画不可。率や人数の正本、積み上げ棒、CSVの値に配分結果を戻さない。

端数が小さいカテゴリーは図で0個になることがあるが、隣接する全カテゴリー一覧には正確な表示精度の割合・人数・分母を残す。「図では約N人／100人」を明記。人数モードでも図は100人あたりの構成であることを説明し、実人数を併記。

左右／上下は100人図セクションで独立切替。狭い画面では上下配置。モバイルではSVGの100人領域を拡大し、数値をHTML一覧で併記。PNG/Copyではexport viewBoxにより数値凡例も含む全体を出力する。

## 地図・表・グラフ

- 地図：既存2×2 small multiplesと地域A/B選択を維持。各カテゴリーに固定5色パレットを適用。階級は元metadataを維持し年度・地域で固定。カテゴリー間の尺度差の注記・凡例を保持。
- メタボの4地図はhover/focus地域を共有。4区分の値をまとめた補助表示を追加。選択地域の切替は既存クリック／Enterを維持。
- 表：全区分割合セルに0〜100%の共通尺度の淡いバーを追加。数値・原典ボタン・中央揃えを維持。人数モードはバーを表示しない。CSVと表コピーの数値は従来どおり。既存の表PNGは数値中心の出力を維持（セルバー・新アイコンは含まない）。
- グラフ：積み上げはmetadata色を共有。淡色に合わせ内部ラベルは濃色文字。小区分の外部ラベルと全値一覧を維持。「区分の推移」は既存地域比較を使用。
- カテゴリー連動は100人図内の凡例ボタンhover/focus、グラフ内の既存強調に限定。ページ全体のカテゴリー連動は未実装。
- 新しいアニメーションは導入せず、100人図・small multiplesのreduced-motion規則を追加。
