# Health Data Vault：健康にいがた21 データ調査台帳

調査・取得日：2026-09-16（Asia/Tokyo）。対象は「にいがたの生活習慣病」令和4・5・6年度版。Webサイト・データベース・ETLの実装は行っていない。

## 1. 調査範囲と結論

公式の各年度ページに掲載されたExcel **48ファイル（各16件）、90シート**をすべて取得し、シート名、セル値・型、数式、保存済み計算値、見出し、注記、結合範囲を読み取り確認した。Excel合計は2,204,056 bytes（約2.2 MB）。補足として3年度の報告書PDF（各59ページ）の利用案内・母集団説明・関連表を確認した。全セルの統計的妥当性を保証する監査や、臨床判定基準の全年度照合までは実施していない。

原本はリポジトリ外の調査用一時フォルダーに取得した。Excelを保存し直したり再計算したりせず、読み取り後のSHA-256一致も確認した。Gitにrawや加工データを追加していない。48ファイルの直接URL・原本ハッシュを本書に記録する。

重要な結論：

- **刊行年度と実績年度を分離する。** R4/R5/R6版の特定健診はそれぞれR3/R4/R5（2021/2022/2023）年度。歯周病・骨粗鬆症の精検結果もそれぞれ前年度の検診に対応する。
- 特定健診は、市町村国保の特定健診費用決済データから把握された受診者の集計。全県民・全保険者・すべての国保受診者を網羅すると解釈しない。受診率の分母となる対象者数は当該Excelにない。
- HbA1c、血糖、血圧、脂質、腎・尿路系、メタボの判定人数はあるが、**BMI・肥満率・eGFRの独立した集計は対象48ファイルで確認できない。** メタボからBMIや肥満率を逆算しない。
- 市町村別表と性・年齢別表は多くの場合別の集計であり、市町村×性別×年齢の交差集計にはならない。特定健診Excelには性別・年齢階級別の内訳がない。
- R4→R5で子宮体がんの地理粒度と健康診査の性別内訳が変わる。がん発見率は受診者10万対、一般の受診率等は％。同じ「率」を一律に扱わない。
- 原本には重複行、Excelエラー、表題の不整合がある。原本の修正ではなく、採否記録・検証・必要な照会を経て加工する。

## 3. 読み方・共通の単位と母集団

以下の16区分では、各区分の「指標・粒度・母集団・単位・接続判断」をその区分に列挙した3ファイルそれぞれに適用する。年度例外は明記する。リンクの表示名はURL末尾の実ファイル名そのもの。シート名は改名せず、前後の空白も含めて記録した。

### 共通定義

- **G（がん検診）**：市町村の事業報告に含まれる対象者・受診者・要精検者・精検受診者。全住民のがん罹患・有病状況ではない。対象者数の対象範囲は年齢・検査方法・地域・年度の表と定義に依存する。
- **H（健康増進事業）**：健康教育・相談・訪問指導等の実施実績。人数、実人員、延人員、回数を別指標にする。参加者や被指導者を患者数と解釈しない。
- **K（健康診査）**：健康増進事業としての健診。報告書p.4では40～74歳の特定健診・特定保健指導の対象とならない者、および75歳以上で生活保護世帯に属する者等を対象と説明。特定健診Tとは別母集団。
- **T（特定健診）**：40～74歳の市町村国保受診者のうち、新潟県国保連合会の費用決済データをもとに新潟県健診保健指導支援協議会が把握する結果（各版p.2）。Excel概要の出典は新潟県健康づくり財団。全保険者・全住民へ外挿しない。

がん検診の人数は人、細胞診等の実施件数は件。受診率・要精検率・精検受診率・早期がん割合・陽性反応適中度・CIN3率等は％、**がん発見率と結核発見率は受診者10万対**。Excelの見出しだけで単位が省略される場合はPDF p.1の式・元の数式・同表の分子分母で裏付ける。検査値そのもの（mg/dL、mmHg、HbA1c％等）の平均・個票ではなく、判定に該当した人数を収録する表である。

自動取得の評価は全ファイル共通で「容易」：認証なしの直接HTTPSリンクから全48件のxlsx取得に成功。ただし自動**解釈・抽出**は別問題で、以下に難易度と条件を記す。「条件付き接続候補」は公開用の接続承認ではなく、定義・分母・原本不整合の検証が済んだ範囲だけ接続できるという意味。

### 7.2 表記・書式と意味

- R5子宮体シートは `子宮体（年齢階級別 ）`、実際の行も年齢区分だが、A1は「市町村別」と記載。R6のA1では年齢階級別になっている。R5を表題だけで市町村データと解釈しない。

- 全90シートの表示状態はvisibleだった。シート名の全角／半角、末尾空白、前立「線」などの原表記は保持し、標準名は別フィールドにする。

### 7.3 欠損・ゼロと丸め

各版の報告書p.2には、数値なしは「－」、数値がありえない場合は「・」、微少（0.05未満）は「0.0」と説明される。一方、Excelには数値0、文字列のハイフン、空欄、「実施なし」、エラーがあり、数値0を「-」と表示する数値書式もある。

処理は原値・セル型・表示形式・注記をセットで判定する。文字のハイフンは自動的に0とせず、`value=null` と欠損理由・原記号を保持する。数値0のセルは真の原値として保持するが、「実施なし」の事業行なら非実施状態を別に持つ。表示された0.0だけから真のゼロを断定しない。PDFの見た目だけからExcelの数値を再構成しない。

報告書の割合は原則小数第1位表示、Excelには丸め前の保存値がある。原値を保持し、表示の丸めと再計算を別工程にする。要精検内容などの複数該当を足して一人一分類の合計検査にかけない。判定不能・未把握・未受診はそれぞれ意味が違う。
