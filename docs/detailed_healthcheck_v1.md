# 詳細な健診項目：第1版（ローカル候補）

## 範囲と表示方針

2021・2022・2023年度実績（2022・2023・2024年度刊行版）。既存の収集済み特定健診Excel3ファイルを使用する。
母集団は市町村国保40～74歳のうち国保連の費用決済データから把握された健診受診者であり、全県民・全保険者ではない。

| 選択項目 | 原表列 | 単位 | 原表階層 |
| --- | --- | --- | --- |
| 貧血検査：判定人数 | AG | 人 | 詳細な健診項目／判定区分（保健指導以上を再掲） |
| 貧血検査：実施件数 | AJ | 件 | 詳細な健診項目／実施件数 |
| 心電図検査：判定人数 | AH | 人 | 詳細な健診項目／判定区分（保健指導以上を再掲） |
| 心電図検査：実施件数 | AK | 件 | 詳細な健診項目／実施件数 |
| 眼底検査：判定人数 | AI | 人 | 詳細な健診項目／判定区分（保健指導以上を再掲） |
| 眼底検査：実施件数 | AL | 件 | 詳細な健診項目／実施件数 |

県計＋30市町村＋13保健所管内、6項目×3年度×44地域＝792値。保健所管内は既存の監査済み対応表と原表の保健所計を使う。
新潟市管内は採用済みの新潟市行を参照し、原表の重複行51は使用しない。別指標の人数・件数や県計・市町村・保健所を合算しない。
保健所の眼底判定人数・実施件数には、柏崎のAI40・AL40で3年度とも空欄がある。6値は欠損を維持し、市町村が0でも補完しない。
16個の数値0は0のまま保持し、空欄・文字のハイフン等と混同しない。未知の欠損記号・単位・比較権限は検証エラーにする。

割合、地図、分布図、構成図、前年差、増減率、トレンド評価は作成しない。
特定健診受診者数（B列）は参考情報であり、詳細検査の分母として使用しない。判定人数と実施件数を別々に表示し、同一人数への読み替えをしない。
概要シートには対応する検査数を分母とする式があるが、市町村への適用・集計対象の対応まで承認したものではない。

## 定義・比較上の制限

- 貧血・眼底の判定人数は両区間pending。主要基準の一致だけでは集計の比較可能性を認定しない。
- 心電図判定人数は2021→2022がpending、2022→2023がincompatible。原本由来の状態をpendingに上書きしない。
- 実施件数は両区間pending。判定人数の基準変更と実施件数の系列を区別する。
- 選択的実施、貧血の高値側処理、眼底単独データの健診本体との結合・除外、服薬の扱い等は未解決事項を継承する。
- 2023年度心電図の人数変化を基準変更だけに帰属させない。

定義の公式出典・年度適用・ページ・原本ハッシュは [調査台帳](data_inventory.md)、[定義調査](tokuteikenshin_definitions.md) のP1・P5・P6・P7を参照。
今後の割合対応は、検査実施件数と判定人数の対象範囲・分母単位を個別に確認してから別契約で実装する。

## 原本・追跡

原本は既存のGit除外 `data/raw/objects/` を読み取り、Excel再保存・再計算・マクロ実行・外部リンク更新はしない。
2021年度 `市町村別`、2022年度 `保険者別`、2023年度 `保険者別 `（末尾空白を含む）を保持する。
各レコードに原値・型・表示形式・実シート名・セル・年度・出典URL・取得日時・SHA-256・欠損状態・比較区間を維持する。
原表の792値を照合し、県計と市町村計・原表保健所計と構成市町村計を、値が揃う列・年度だけ別々に検証する。
公表数表には6列×31採用行×3年度＝558セルから分析表へのリンクを追加。元セル値・注記・既存リンクは変更しない。

## 再現・公開との分離

`hdv.site_release build` の `--include-detailed` は `--count-only` と既存の腎・尿路系契約を前提にした追加機能。
既存の公開投影・保健所契約を先に検証し、その後に追加する。候補検査時には追加部分を除いて既存契約を再検証し、再構築した全候補との完全一致を検証する。
既存指標・分析・地図・公開方針は変更しない。追加部分を除いた候補は承認済み `1e0b2f10...c9b17` と完全一致した。

実行例（専用worktreeから、データルートは一つ上の既存 `data/`）：

```powershell
python -m hdv.site_release build --data-dir .. --analysis-release f66a35326c7f394b31ef7a8e4fb46bdbddbd28701583248afd9d8edfda19ac17 --include-renal --count-only --health-centers --derived-zero --annual-facts --include-detailed
python -m hdv.site_release validate --data-dir .. --release-id 7f4b5b8dfee4bd415413442bff14884d03d8f1826644614ba0ef86f9459804c3
python -m hdv.serve --data-dir .. --web-dir web/dist --site-review-release 7f4b5b8dfee4bd415413442bff14884d03d8f1826644614ba0ef86f9459804c3 --port 4196
```

Pythonにはプロジェクトのopenpyxlと、保健所境界用のshapelyが必要。今回の環境では既存 `data/health-center-deps/` をPYTHONPATHに追加して使用した。
設定ファイルのバイトハッシュも照合するため、Windowsの自動CRLF変換を受けたcheckoutでは元のLFバイトに合わせる必要がある。照合ガードを無効化しない。
一時ファイルは `data/detailed-review/tmp/` に分離。取得・候補生成・確認は公開承認ではない。
公開中の `current.json`、承認済みrelease、Web配信用公開JSONは切り替えていない。
