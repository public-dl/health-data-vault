# Copy / PNGの成果物境界修正（2026-09-20）

## 原因と修正

従来の画像生成には、カードの後へ原典・レコード・release等の文字列を描き足す処理が残っていた。今回、その追記API自体と固定の下部余白を廃止した。

- `web/src/export-surface.tsx` の共通 `ExportSurface` が可視成果物を囲む。任意の親要素・sectionへのフォールバックは行わない。
- 主要値、地図、表、100人図、グラフを同じ境界方式へ移行。比較出力は各カードのsurfaceだけを取得して合成する。
- 詳細出典モーダルはsurface外に維持。sourceリンクと可視DATA NOTESは画像に残す。
- `cardsPng` は境界未指定、詳細情報・dialog・detailsを内包する対象を拒否する。閉じた詳細DOMにも依存しない。
- `outputPng` が共通のPNG Blobを、CopyではClipboardItem、保存ではdownloadへ渡す。テキスト追記なし。CSVの内容は変更しない。
- 表の行高を維持し、captionの高さ二重計上とDATA NOTES手前の余白を防ぐ。多数の人物SVGも不要なCSS複製を避け、中央配置・人型サイズを維持する。
