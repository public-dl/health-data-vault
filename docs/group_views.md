# 全区分表示（public-3）

実装日：2026-09-19。単区分の初期表示と任意2地域比較を維持する。

## 公開契約

`hdv/public_config/groups.json` の明示的なグループ定義を使用する。表示名から推測しない。現在のグループは `metabo` と `guidance`。カテゴリ―は既存indicator_idへの参照であり、新たな観測レコードを作らない。

- グループ：group_id、表示名、definition_version、audit_reference、composition_rule、denominator_indicator_id、監査済み年度、必須category_id、allowed_views。
- カテゴリー：category_id、label、order、indicator_id、color、rate_map_breaks。count_map_breaksは候補生成時に既存の公開指標の階級を取り込み、公開JSONへ保存する。
- 公開データ：既存recordsとdenominator_recordsをそのまま保持し、indicator_groups・composition_validationを追加する。
- 構成検証はグループ×実績年度×地域ごとに記録。構成レコードID、分母ID、人数合計、分母値、差、検証状態、グループ定義版を保持する。これは検証証跡であり、合計の新指標ではない。
- 各割合の比較判定は既存derived_rateに保持する。分母の人数系列のpending判定を変更しない。
- グループ設定の原本スナップショットを候補ディレクトリのgroups.jsonに保存し、manifestのgroups_sha256と照合する。候補JSON全体も従来どおりSHA-256で固定する。後日のグループ設定編集で過去候補を上書きしない。
- public-1/public-2の表示互換性を維持。グループ定義を持たない旧形式では全区分選択肢を出さない。既存public-2候補は旧契約で再構築・再検証可能。

## 検証と異常時

公開Validatorは既存の割合検証に加え、必須カテゴリーの完全性・一意性・順序、未知ID、公開指標との対応、rate.componentsと分母の一致、同年度・地域・母集団・原本版・シート・行、正の分母、分子の範囲、合計一致、個別provenance、監査済み年度・定義、地図階級・表示許可を検査する。

欠損、分母0、区分欠落、未知カテゴリー、母集団・定義・原典の不一致では候補生成／公開検証を停止する。新年度を既存監査範囲へ自動追加しない。現在の公開版を自動切替せず、人手確認と新しい承認を必要とする。UI側でも構成証跡と対象レコードが一致しなければ構成を表示しない。

人数合計で検査し、表示丸め後の割合合計では判定しない。割合を再正規化・差分配賦しない。判定不能を欠損や0と同一視しない。

## UI

- optgroupごとに全区分と単区分を並べる。初期値は従来どおりメタボ基準該当・割合。
- 地図「全区分一覧」は1地域のカテゴリー一覧。PC・幅760px以上は2列、狭い画面は1列。地域A/Bは実際の地域名で切替。一度に8枚は描画しない。
- 地図「地域比較」は1カテゴリーを選び、既存の左右／上下を利用。単区分用部品を再利用する。
- カテゴリー別に固定階級を持ち、地域・年度変更で再計算しない。カテゴリー間で尺度が異なることを表示する。単区分表示の従来階級設定は変更しない。
- 表は地域ごとに年度×カテゴリーの固定順。割合主値＋人数補助、年度共通分母を1回表示。公表年度・検証／比較状態、原典リンクを保持。左右表示の年度行を揃え、狭幅では上下へ変換する。
- 全区分グラフの初期表示は構成。割合は監査済み割合をそのまま積み上げ、人数は原人数を積み上げる。年ごとに地域A/Bを隣接配置する。
- 地域の表示ON/OFFは最低1地域を保持。人数軸は全選択地域を基準に固定、割合軸は0〜100%。カテゴリー操作は強調のみで、非表示・再正規化をしない。
- 全カテゴリーの数値を常時表示する。文字幅を計測し、高さ・幅が足りる場合は区分内、それ以外（実値0を含む）は外部ラベルと引き出し線で表示する。全年度・地域のラベル矩形と棒をまとめて衝突判定し、上下移動を中心に左右も調整する。配置困難時は下方へ領域を拡張し、ラベルを省略しない。
- スマートフォンではグラフを横スクロールでき、直下の地域・年度別一覧でも全値をタップ不要で読める。SVG補助一覧を保持し、コピー・PNGにも全値を含める。hover/focus/click/tapの詳細は補助として維持する。実値0は0.0%／0人、欠損はvalue_stateに従う表示不可として区別する。
- 「区分の推移」は1カテゴリーを選び、既存の2地域折れ線・ラベル配置・軸制御を再利用。8折れ線を同時表示しない。
- 見どころは選択年度の検証値だけから生成する。健康上の優劣や施策の効果を説明しない。
- 全区分の出典は地域→年度→カテゴリー順のレコード一覧。各表セル・詳細カテゴリーから単一原典へ直接進める。人数表示でも派生割合の分子分母・式を確認できる。

## 地図階級（割合、%）

階級は視認性のための表示設定で、医学的な判定閾値ではない。各列は4つの境界で5階級を定める。候補の表示設定としてレビュー対象。

| グループ | カテゴリー | 境界 |
|---|---|---|
| metabo | case | 15, 20, 25, 30 |
| metabo | preliminary | 8, 10, 12, 15 |
| metabo | noncase | 50, 60, 70, 80 |
| metabo | indeterminate | 0.1, 0.5, 1, 2 |
| guidance | active | 2, 4, 6, 10 |
| guidance | motivational | 8, 10, 12, 15 |
| guidance | none | 70, 80, 85, 90 |
| guidance | indeterminate | 0.1, 0.5, 1, 2 |

## 出力

- 全区分地図一覧を1枚の2列PNG／画像コピーへ出力。各カテゴリーの凡例を保持。個別地図の出力も維持。
- 表コピーは年度×カテゴリーの横持ち。分母を年度ごとに1回記載し、原典参照・releaseも付加。
- CSVは既存indicator_idを持つ縦長。group_id/category_id/category_orderを追加し、人数・割合いずれの表示でも分子分母・計算式・原典を保持する。
- グラフPNG／コピーは表示中の地域のみを含む。全カテゴリーの凡例、細い区分を含む数値補助一覧、年度、単位、母集団、release、未承認表示を保持する。

## 対象外

5地域比較、NDB、性別・年齢別、データアップロード、外部公開、自動承認は実装しない。将来の重複カテゴリーや異なる分母の分類は現在のpartition契約では許可されず、別の監査・契約が必要。
