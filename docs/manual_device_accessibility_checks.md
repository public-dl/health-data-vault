## B2：実機Safari

1. トップから全8テーマを開く。見出しと選択テーマが一致し、白画面・本文全体の横はみ出しがないこと。
2. 「表示条件」を開き、指標・年度・地域A/Bを変えて閉じる。選択結果が保持されること。
3. 血清尿酸の2023年度・県計で6,936人／77,202件／9.0％を確認する。2022年度へ変え、6,841人／78,926件／8.7％になること。
4. Safariの戻る・進むで、URL・年度・表示が一緒に復元されること。
5. 地図の地域を選択して値・状態を確認する。真の0と算出不可が数字・状態名でも区別できること。
6. 数値表と公表数表を横スクロールする。本文全体は横に流れず、表の中で移動できること。
7. 縦向き・横向き、大きめの文字設定で、注記・送信欄・閉じるボタンが欠けないこと。

## B3：VoiceOver等

1. 画面先頭からリンク・見出し・ランドマークを移動し、「本文へ移動」で本文へ入れること。
2. 条件欄のテーマ・指標・表示値・年度・地域A/Bが、名前と現在値を伴って読まれること。
3. 各テーマの諸元・出典を開き、ダイアログ名が読まれ、読み上げ位置とキーボードフォーカスが内部にあること。
4. 前後移動で外の本文へ抜けず、閉じると元の呼び出しボタンへ戻ること。外付けキーボードがある場合はTab／Shift+Tab／Escapeでも確認する。
5. 表の列見出し・実績年度・掲載年度・選択中の表示が区別して読まれ、数値と単位の対応を追えること。
6. 欠損／算出不可／真の0の読み上げを確認する。色だけを手掛かりにしなくても状態が分かること。
