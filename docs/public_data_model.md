# 第1弾Web公開データモデル

現行候補の `public-3` JSON（旧public-2と読み取り互換）は、承認前の候補と承認済みreleaseを分離する。既存の `0.1` JSONLスキーマや原本は変更しない。実績年度・掲載年度・母集団・原見出し・原値状態・シート・セル・原本ハッシュ・取得日時・定義版・比較状態・検証状態は原レコードから引き継ぐ。

## 公開条件

- 公開指標設定に存在し、元の指標辞書でもcompatible。
- 地理階層は県計または個別市町村。市計・町村計・保健所計・国保組合・重複除外行は配信対象外。
- 原本から再抽出・再検証した値と一致。数値は検証passed、採用済み、comparison_allowed=true。
- 欠損は値null・元のvalue_stateを維持し、比較を許可しない。現在の744レコードには欠損なし。
- 年度×地域コード×指標IDが一意で、選択指標・年度・地域の組合せに欠落なし。存在しない組合せを0生成しない。
- 原値は人・件のreported_count。監査済みの指標のみ、別のderived_rateに受診者構成割合を持つ。測定平均・性別・年齢階級の系列は生成しない。
- 収録年度が連続し、全隣接区間がcompatibleであることを検査する。区間が混在する公開版は将来の別契約として扱い、今のUIで無条件再生しない。

## JSON構造

| キー | 内容 |
|---|---|
| schema_version / input_run_id | 公開形式の版と入力実行ID |
| years / population_scope | 実績年度集合と対象者範囲 |
| indicators | ID、表示名、グループ、説明、単位、統計量、比較区間、地図階級 |
| geographies | 原地域名、表示名、地理階層、5桁自治体コード。県計のみ2桁15 |
| records | 原観測レコード＋geography_code＋record_id＋監査済みderived_rate |
| denominator_records | 割合の分母となる受診者数と出典。人数系列の比較許可とは別管理 |
| map | 30市町村のFeatureCollectionと取得・加工・境界版メタデータ |
| insights | 指標×地域×表示年度×表示単位の定型説明、参照record ID、計算式、生成方式 |
| source_validation / warnings | 原本再検証の結果概要と残る制約 |

record_idは原本SHA・原シート・セルから生成。設定を追加してもUIの指標名・選択肢・グラフ描画に個別指標コードを追加する必要はない。元の検証辞書・構造契約が対応していることは別条件。

人数の地図階級は公開版の全年度・全市町村の最大値から生成した等間隔の固定階級。健康リスクの閾値ではない。同一release内では年度切替で変えない。公開版間で階級が変わる可能性はあるため、図の凡例とrelease IDを保持する。

## 原本との一致確認

buildとinspectは入力runのcollection/run/recordsを一時領域へコピーし、既存Validatorで原本から再検証する。生成済みのpassedフラグだけを信用しない。公開候補の検証時は再構築したJSON全体との一致も検査するため、値、説明文、地図、指標名の改変は検出される。

候補JSONの正規化したバイト列のSHA-256をrelease IDにする。候補は承認で上書きせず、別のreleaseディレクトリへ保存。承認記録はデータハッシュ・確認者・確認日時・再利用条件の確認・検証結果を保持する。

## 画面と出力

地図は市町村別の受診者構成割合または人数。割合の階級は公開指標設定の固定値で、健康リスクの閾値ではない。選択市町村は県全域地図上で強調し、市内を分割・配賦しない。県計は正本の県計を表示する。原表の45地域行を合計しない。

表は3年度の選択単位の値と報告人数／受診者数。CSVに年度・コード・指標・値状態・比較/検証状態・出典セル・原本SHAを含む。テキストコピーはTSV。画像には単位・母集団・公式ページ・release ID・未承認表示（プレビュー時）を付ける。

折れ線は同じ地域・指標・母集団・単位で、連続年かつ両レコードが比較可能な場合だけ接続する。欠損を飛び越えた接続はしない。任意の地域A/Bを同じ軸の選択単位で重ね、グラフは1枚とする。全区分では構成積み上げを標準とし、1区分を選ぶ折れ線へ切り替えられる。

説明はPythonの検証値から生成した定型文。数値・差分と入力record IDを保持する。生成AI APIは接続しておらず「AI生成済み」と表示しない。将来のAI文章化でもこの事実集合と人手承認を必須にする。

## public-2：受診者構成割合の追加

既存の人数レコードを維持し、derived_rateとdenominator_recordsを追加。割合の定義と検証契約は [recipient_percentage_audit.md](recipient_percentage_audit.md) が正本。見どころはmeasure=count/rateで分離し、割合の差はポイント表示。公開UIは割合が設定された指標のみ割合表示を許可し、初期表示は割合。public-1の承認済み旧版も人数表示で読み込み可能。新規生成はpublic-2を使用する。

## public-3：全区分表示

現行の単区分UIは任意2地域を1枚の折れ線で比較する。全区分モードを追加しても単区分の初期表示・地域選択・比較操作を維持する。

public-3は既存の人数・派生割合・分母を変更せず、明示的なindicator_groupsとcomposition_validationを追加する。両グループを同じ汎用UIで表示し、全区分を新しい統計指標として扱わない。グループ設定・検証結果も候補とreleaseのハッシュ対象となる。

契約、カテゴリー、地図階級、UI、異常時の停止、出力仕様は [全区分表示](group_views.md) を参照。旧public-2の再検証を維持し、グループ定義を旧データから推測しない。
