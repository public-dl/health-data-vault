# 血圧・脂質の04：年度実績値の参考表示

2026-09-21。ユーザーの明示仕様に基づき、pendingの年度値を点と直線で参考表示する。既存の `connect`、Validator、comparison_allowed、comparability、releaseは変更しない。前年差・増減率・トレンド評価は生成しない。

- 共通React/SVGカード：`web/src/reported-charts.tsx`。外部chart library追加なし。
- 集計・CSV：`web/src/reported-chart-model.ts`。
- 全年度を個別の実績値として表示。グローバル年度選択は分布・独立棒へ適用し、年度グラフの年度範囲は収録年度を維持。
- 04は表示条件が人数の場合も検証済みの割合を表示し、その旨をグラフの見方に明記。
- 年度別実績値のY軸は0始まり。固定上限は受診勧奨50、保健指導40、実人員80、中性脂肪50、HDL15、LDL70、総コレステロール60（%）。独立棒のみ共通0～100%。地図の固定レンジとは別の表示metadata。
- 年度別実績値の県計は破線＋白抜き円。市町村は実線＋四角／ひし形。同じindicator色を共有。
- 分布は選択年度のmunicipality行だけを使用し、同一コード重複をエラーとする。県計・集計行は除外。欠損は0へ変換せず、有効数を明示。四分位点は昇順値の位置 `(n-1)*p` を線形補間（非加重）。ひげは最小値と最大値。
- 脂質独立棒は項目を合計しない。
- ExportSurface内の可視カードのみCopy/PNG化。年度別の数値表、凡例、軸、pending注記を含める。出典詳細は既存モーダルで表示。
- CSVはグラフ元の検証済み年度レコード。人数・受診者数・割合・地域・年度・指標・pending・release・出典を保持。分布CSVは集計元の市町村レコード＋県計参照値（地域種別で識別）を出力する。

確認：TypeScript、Vite build、単体／回帰テスト。PC 1366×768で年度別／分布／独立棒、Copy/PNG生成と同一ハッシュを確認。
