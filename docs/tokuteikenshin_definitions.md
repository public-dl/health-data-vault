# 特定健康診査等結果報告：令和3・4・5年度実績の定義調査

調査日：2026-09-16（日本時間）。対象は2021・2022・2023年度の**実績**。調査のみで、取得・変換・公開システムは実装していない。

## 1. 結論と判定の範囲

年度別の新潟県「健（検）診ガイドライン」と、新潟県健診保健指導支援協議会「特定健康診査等結果集計報告」を照合した。主要な数値閾値、メタボ判定、保健指導の階層化、検査の実施条件について、R3→R4→R5で変更は確認されなかった。ただし、**判定基準が同じことと、公開Excelの人数を同一定義の系列として公開できることは別**である。

特に、随時血糖の用途別基準、個別検査の服薬者の扱い、医師の判定と数値からの再判定の対応に未解決事項がある。したがって、以下では「公式基準の比較」と「対象Excelの時系列接続」を分ける。未確認事項を「変更なし」とは扱わない。

- `compatible`：ここで明示した意味・母集団・単位の範囲で、比較を妨げる定義変更が確認されない。
- `incompatible`：定義変更を確認したため、そのまま同一系列にできない。
- `pending`：必要な対応関係、分母、服薬者の扱い等を公式資料で確定できない。未確認のまま接続しない。

「比較可能」は住民全体の有病率、年齢調整済みの健康状態、同一人物の経年変化を意味しない。今回の対象は集計表の判定人数である。実績R6以降への外挿もしない。

## 3. 母集団・単位・集計上の共通条件

S-aによる報告全体の対象は、国保連に保管された県内市町村国保・県内3国保組合等の健診データ。40歳未満、生活保護、後期高齢者等も含むため、**報告全体と今回の市町村国保40～74歳のExcel範囲は同一ではない**。法定報告データとも異なる。S-eでは国保組合計が県計とは別に掲載されており、足し込まない。全国・全保険者・全住民の分母に接続しない。

年齢は各実績年度末（翌年3月31日）基準（S-d）。毎年の受診者集団であり固定コホートではない。性別・年齢構成、受診率、検査実施率の変化が粗い人数・割合の変化に影響する。

Excelの単位は人数または実施件数。以下に記すmg/dl、%、U/L等は**判定に用いる検査値の単位**であってExcelセルの単位ではない。概要シートの基本項目割合は総受診者数を分母とするものがあり、検査実施者中の陽性率には読み替えられない。貧血・心電図・眼底等には実施件数を分母とする割合もある。指標別に元の数式を維持する。

S-b・S-cは空白類を除いた抽出テキストで3年度一致を確認した。主要な共通処理は以下。

| 項目 | S-bに記載された有効範囲等（R3・R4・R5共通） |

| 身長・体重・BMI・腹囲 | 身長100.0–250.0、体重20.0–250.0、BMI10.0–100.0、腹囲40.0–250.0。BMIは身長・体重から集計時に再計算 |

## 4. 指標別の公式基準

### 4.1 メタボ判定と保健指導レベル

**メタボ（G3–G5/G-c・G-d）**：腹囲男性85cm以上・女性90cm以上、または内臓脂肪面積100cm²以上相当を前提とし、次の3リスクのうち1つを予備群、2つ以上を基準該当とする。

| リスク | R3・R4・R5共通 |
|---|---|
| 脂質 | TG≧150mg/dlまたはHDL＜40mg/dl、またはコレステロールを下げる薬の服用 |
| 血圧 | 収縮期≧130mmHgまたは拡張期≧85mmHg、または降圧薬服用 |
| 血糖 | 空腹時≧110mg/dl、代替HbA1c≧6.0%、またはインスリン注射／血糖を下げる薬の使用 |

空腹時血糖とHbA1cを両方測定した場合は空腹時血糖を優先。随時血糖のみの場合は血糖検査未実施として扱う。これは8学会基準をそのまま転載したものではなく、HbA1cによる代替と予備群を含む県資料の定義である。Excel C–Fは非該当・予備群・基準該当・判定不能。服薬者を一律除外してメタボ率を作らない。

**保健指導レベル（G3–G5/G-c・G-e）**：腹囲基準以上を群1、腹囲基準未満かつBMI≧25を群2とする。追加リスクは血圧≧130/85のいずれか、TG≧150またはHDL＜40、空腹時（やむを得ない場合は随時）血糖≧100またはHbA1c≧5.6。喫煙は前三者のリスクが1つ以上の場合のみ加算。空腹時血糖とHbA1cの両方がある場合は前者を優先する。

| 群 | 積極的支援 | 動機付け支援 | 情報提供 |
|---|---|---|---|
| 腹囲基準以上 | 追加リスク2以上 | 1 | 0 |
| 腹囲基準未満・BMI≧25 | 追加リスク3以上 | 1または2 | 0 |

血圧・脂質・血糖の治療薬使用者は特定保健指導の対象としない。65～74歳は積極的支援に該当しても動機付け支援とする。Excel L–Oはこの**対象者のレベル判定**であり、保健指導を実際に受けた人数・終了者数ではない。服薬者に別途保健指導を実施できることと、この階層化の対象は区別する。

### 4.3 実施条件・測定方法・服薬の解釈

次はG3–G5/G-a・G-bで共通。閾値だけでなく検査を受ける条件を保存する必要がある。

- **血糖**：空腹時は10時間以上食事なし。基本項目として空腹時血糖またはHbA1c。やむを得ず非空腹で、HbA1cを測定しない場合は食事開始から3.5時間未満を除いて随時血糖を利用できる。任意追加検査としての随時血糖と区別する。血糖は電位差法・可視／紫外吸光光度法等、HbA1cは免疫法・HPLC・酵素法等。HbA1cのNGSP表記は3年度のS-aでも確認した。
- **脂質**：TG≧400または食後採血時はLDLに代えてNon-HDLを使用できる。LDLは条件を満たす場合のFriedewald式、または直接法。Non-HDL＝総コレステロール－HDL。Excel UにNon-HDL代替例がどう反映されるかは明示されていない。
- **肝機能**：AST・ALTは紫外吸光光度法等、γ-GTは可視吸光光度法等。S-cはAST・ALTにJSCC、γ-GTにIFCC（JSCC）標準化対応法を記載。年度別に各施設が使った試薬・測定機器の実績は未確認。
- **尿糖・尿蛋白**：基本検査。原則中間尿を試験紙法で検査する。定性記号を数値濃度や尿アルブミンに変換しない。
- **クレアチニン**：詳細な健診。血圧≧130/85のいずれか、または空腹時血糖≧100、HbA1c≧5.6、随時血糖≧100のいずれかに該当し、医師が必要と認める場合。全受診者への一律検査ではない。既に他院の最近の検査結果等が明らかで再検査不要と判断される場合もある。酵素法で測定し、eGFR＝194×Cr^−1.094×年齢^−0.287（女性×0.739）。Crの人数をeGFR低下人数に置き換えない。
- **眼底**：詳細検査の血圧条件は140/90、血糖条件は空腹時126・HbA1c6.5・随時126。医師の必要性判断を伴う。当年度血圧が条件未満で血糖結果不明の場合、前年度血糖での条件該当も含む。
- **心電図**：血圧140/90以上のいずれか、または不整脈疑い、かつ医師の必要性判断。実施条件と判定基準の改訂を混同しない。

**服薬の規則は用途別**：メタボは治療をリスクに含め、特定保健指導の階層化では対象から除外する。一方、S-eの各検査「保健指導以上」について、服薬だけで計上するのか、検査値だけで判定するのか、医師判定を優先するのかを一意に示す説明は確認できなかった。S-gの「服薬中の者を含む」という注記をS-e全列の規則に拡張しない。

G-cでは医師が数値基準を目安に個別判断することが示される。したがって、Excelの「医師の判断」と、こちらで数値から再計算した「閾値超過者」は同じ指標ではない。
